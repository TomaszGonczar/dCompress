# Demo — the Claude continuity loop: snapshot, compact, restore

[`claude-slice-0001.md`](claude-slice-0001.md) records a one-shot `preview`: a transcript in, a pack
out, nothing persisted. This document records the other half of the claim — the experimental OG-85
continuity slice — against a synthetic transcript that spans a compaction boundary. Every byte quoted
below is regenerated by the commands above it, and `test/continuity-demo.spec.ts` fails if a stream,
a count, or a hash drifts from what the CLI renders.

The fixture is invented (`test/fixtures/claude/continuity-0001/`). No real session, session id,
transcript prose, or host path appears in this document, and the store is a disposable `mktemp -d`
directory: nothing under `~/.claude` is read or written.

## The loop this demo exercises

Claude fires `PreCompact` before it compacts. The bridge checkpoints the transcript and opens an
injection epoch. Claude compacts, and everything before the boundary leaves the context. Claude fires
`SessionStart`; the hook answers with the pack as `additionalContext`, exactly once for that epoch, so
a duplicated event cannot inject the same bytes twice. Work continues, the transcript file grows, the
next `PreCompact` checkpoints the grown file, and the next `SessionStart` carries the larger pack.
`restore` is that same read without a hook, for a human or a CI job.

## Reproduce it

From the repository root, after `npm ci && npm run build`:

```sh
STORE="$(mktemp -d)"
SID=fixture-continuity-0001
FIX=test/fixtures/claude/continuity-0001

# Epoch 1, checkpointed explicitly: this surface needs no hook.
node dist/cli.js snapshot --session "$SID" --transcript "$FIX/precompact.jsonl" --store "$STORE"

# Epoch 1 ends. PreCompact opens the injection epoch.
printf '%s' '{"session_id":"fixture-continuity-0001","transcript_path":"test/fixtures/claude/continuity-0001/precompact.jsonl","hook_event_name":"PreCompact"}' | node dist/cli.js hook --event precompact --store "$STORE"

# The context is fresh. Deliver, then let the same epoch deliver again.
printf '%s' '{"session_id":"fixture-continuity-0001","transcript_path":"test/fixtures/claude/continuity-0001/precompact.jsonl","source":"compact"}' | node dist/cli.js hook --event session-start --store "$STORE"
printf '%s' '{"session_id":"fixture-continuity-0001","transcript_path":"test/fixtures/claude/continuity-0001/precompact.jsonl","source":"compact"}' | node dist/cli.js hook --event session-start --store "$STORE"

# Epoch 2 ran past the boundary, so the transcript file has grown.
printf '%s' '{"session_id":"fixture-continuity-0001","transcript_path":"test/fixtures/claude/continuity-0001/transcript.jsonl","hook_event_name":"PreCompact"}' | node dist/cli.js hook --event precompact --store "$STORE"
printf '%s' '{"session_id":"fixture-continuity-0001","transcript_path":"test/fixtures/claude/continuity-0001/transcript.jsonl","source":"compact"}' | node dist/cli.js hook --event session-start --store "$STORE"
printf '%s' '{"session_id":"fixture-continuity-0001","transcript_path":"test/fixtures/claude/continuity-0001/transcript.jsonl","source":"compact"}' | node dist/cli.js hook --event session-start --store "$STORE"
printf '%s' '{"session_id":"fixture-continuity-0001","transcript_path":"test/fixtures/claude/continuity-0001/transcript.jsonl","source":"resume"}' | node dist/cli.js hook --event session-start --store "$STORE"

# The explicit surface reaches the same chain.
node dist/cli.js snapshot --session "$SID" --transcript "$FIX/transcript.jsonl" --store "$STORE"

# And the chain, rendered four ways.
node dist/cli.js restore --session "$SID" --store "$STORE"
node dist/cli.js restore --session "$SID" --store "$STORE" --max-bytes 1400
node dist/cli.js restore --session "$SID" --store "$STORE" --max-bytes 640
node dist/cli.js restore --session "$SID" --store "$STORE" --include-evidence
node dist/cli.js restore --session "$SID" --store "$STORE" --max-bytes 200
```

The last command is expected to refuse: it asks for a budget smaller than the header plus the elision
notice, so it exits `4` without writing to stdout.

`transcript.jsonl` begins with the exact bytes of `precompact.jsonl`: the second file is the first,
plus the `system`/`compact_boundary` record, its `isCompactSummary` follow-up, and epoch 2. That is
what Claude Code's transcript does at a compaction — it records the boundary and keeps appending to
the same file — and it is why the restored chain here is a superset of its own earlier checkpoint
rather than a lossy union. [The last two sections](#what-the-pack-lost-or-never-had) say what that
leaves unshown.

[`fixture.manifest.json`](../../test/fixtures/claude/continuity-0001/fixture.manifest.json), so the
committed fixture and this document cannot diverge silently.

Two checkpoints, chained by `previous_hash`, named after the payload hash they contain. Directories

injection epoch is the delivery ledger, and it is the reason steps 4 and 7 are empty.

## What survived the compaction

- The user's constraint, verbatim, with its cue: `we must`.
- The failure and its fix as one auditable pair: `error.raised` from lines 9–10, `error.fixed` from
  lines 19–20, with the normalized assertion signature both share.
- A file identity that spans the boundary: `src/export.ts`, `edits=2`, evidence lines 5, 6, 16, 17.
- Both tasks: `item:1` untouched, `item:2` showing `text=completed` because the update after the
  boundary replaced its text.
- The health of the run: `coverage: 1000000 ppm`, 0 unmapped calls, 0 diagnostics, so a reader knows
  the pack is not quietly thin.

## What the pack lost, or never had

- **The user's last instruction.** Line 18 ("…the CLI help text…") contains no decision cue and is not
  a task, so it yields no fact. A post-compaction agent reading only this pack would not know that
  instruction was given. This is the failure mode the demo was built to expose, and it is why the
  fixture carries it.
- **The agent's own compaction summary.** The `isCompactSummary` record is recognized and skipped: its
  prose never enters a pack, by design (ADR 003). Nothing here is model-written, and nothing here is
  a substitute for the summary either.
- **An explicit open/done state on a task.** `todo.state` renders `text=`, and `text` is the subject
  for a creation and the status word for an update — `item:1` reads as its subject, `item:2` reads
  `completed`. Absence of an update is the only signal that a task is still open.
- **Everything the earlier checkpoint holds and the newest does not.** On this fixture: nothing. The
  newest checkpoint was cut from a transcript that still contained epoch 1, so its payload already
  held every earlier fact and the chain merge added no fact at all; the `unbacked` marker, which
  exists to mark exactly those earlier-only facts, never appeared. The chain's contribution here is
  provenance (`previous_hash`), the monotonic health union, and the place to attach a checkpoint when
  a transcript *is* rotated. That is a weaker claim than "the store remembers what the transcript
  forgot", and this document will not make the stronger one.
- **Facts from an empty payload.** A budget too small for a fact drops it and says so; a merged chain
  never invents a fact to fill the gap.
- **Git state, secrets, and anything outside the transcript.** The Claude adapter emits no
  `git.state`, secret redaction is not implemented, and no fact can cite evidence that is not in the
  transcript.

## What this demo does not show

- **Injection into a live agent.** The hook output above is what Claude Code receives; this repository
  never installs itself, never edits live Claude configuration, and has no `install`/`uninstall`.
- **A large or repeated-compaction session.** Two epochs, 8 tool calls, one file. Retention across
  many cycles is not measured here, and nothing in
  [`docs/benchmark/native-compaction-retention.md`](../benchmark/native-compaction-retention.md)
  runs in CI.
- **That injection improves outcomes.** This is a fidelity demo, not the three-arm test of
  [`docs/DEVELOPMENT_PLAN.md`](../DEVELOPMENT_PLAN.md) §7.1.
- **Reproducibility of the store.** Only payload hashes are reproducible; the envelope is not, and
  the injection ledger is host state by construction.
- **Windows.** CI covers Ubuntu and macOS only.
